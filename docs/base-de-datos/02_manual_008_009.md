## 3. Paso a paso

**Pasos 2, 3 y 8 (Database Actions).** OCI › Autonomous Database › Database Actions › SQL, con ADMIN. Pega el archivo completo y pulsa **Ejecutar script (F5)**, no Ctrl+Enter. En «Salida de script» cada cambio aparece como `OK: ...`. Los tres se pueden repetir sin daño.

**Paso 6 (contenido).** Desde `backend/` en el servidor:

```bash
python herramientas/contenido.py validar     # debe decir 0 errores
python herramientas/contenido.py importar    # crea blender_principiante y blender_principiante_intermedio
```

`importar` lee `frontend/src/data/modulos/*.json`. Los módulos de la v2 viven ahora en `modulos/archivo/` y no se leen. Si las columnas de 008 están vacías en un curso que ya existía, `importar` las llena; no toca nada más de los cursos existentes.

**Paso 8 (archivar).** 009 primero comprueba que `blender_principiante` esté publicado. Después archiva el curso `blender`, sus niveles y módulos, y las prácticas `blender.n1.*`, y escribe cuántas filas cambió en cada tabla.

## 4. Cómo saber que salió bien

Las consultas del final de 008 y 009 deben mostrar:

- las 18 tablas con `OK` (CURSOS con 14 columnas);
- `blender_principiante` y `blender_principiante_intermedio` con ruta `blender` y estado `publicado`, y `blender` con estado `archivado`;
- `progreso_v2` con el mismo número que antes: el progreso no se tocó.

En la PWA, el catálogo muestra los dos cursos nuevos (01 y 02) y los dos próximos bloqueados. En Blender, el add-on 3.0 muestra el mapa de cursos en «Mi curso».

## 5. Si algo sale mal

- **El catálogo quedó sin Blender:** se ejecutó 009 antes del paso 6. Ejecuta el bloque «DESHACER» del final de 009 (quita los `--`), haz el paso 6 y vuelve a ejecutar 009.
- **Volver a la v2 completa:** el bloque «DESHACER» de 009 republica el curso viejo. Las columnas de 008 pueden quedarse: el backend v2.2 las ignora.
- **Perdí datos:** no debería pasar, porque ningún script borra. Si pasa, el respaldo del paso 1 se carga con `migrar.py importar` en una base vacía ([03_migracion.md](03_migracion.md), §5).
