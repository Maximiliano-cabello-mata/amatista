# Ramas del motor (`amatista.rama/1`)

Cada archivo de esta carpeta es una **rama** del Corazón Amatista: qué
programa, qué extensiones, qué umbrales del andamio y si la señal se hace
sola. Una rama puede heredar de otra (`"hereda"`) y quitar extensiones
(`"quitar"`). Una idea nueva para el motor se prueba como rama o como
extensión, no como una versión nueva del motor.

| Rama | Programa | Para quién |
| --- | --- | --- |
| `blender-principiante` | Blender | La del add-on por defecto |
| `blender-reto` | Blender | Quien ya domina el módulo |
| `aframe-web` | A-Frame | Retos del Motor Web en la plataforma |

Revisar las ramas: `python engine/herramientas/corazon.py ramas`.
Referencia: [el Corazón Amatista](../../docs/motor/referencia/23_corazon.md).
